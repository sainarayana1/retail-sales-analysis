# Retail Sales Performance Analysis
**Tools:** SQL (SQLite) | Python (pandas, matplotlib) | Excel (openpyxl, SUMIFS) | Power BI (DAX)

An end-to-end data analysis project on Superstore-style retail data (about 10K orders, 4 years, 3 categories, 4 regions).
It cleans the data, answers business questions with SQL, finds patterns with Python, summarises results in Excel and visualises them in Power BI.

## Business questions
1. How are sales and profit trending month by month and year over year?
2. Which categories, regions and customers drive revenue?
3. Where do we lose money, and how much does discounting contribute?
4. How long does shipping take for each ship mode?

## Key findings (from the data in this repo)
- Total sales of about $7.97M, profit of about $1.43M, margin of about 17.9%.
- **Discounting hurts profit:** margin is 25.5% with no discount, 11.1% at 1-20%, **-8.1% at 21-40%** and **-24.1% above 40%**.
- Furniture margin (about 9.7%) is less than half of Office Supplies and Technology (about 21%).
- Technology generates about 65% of sales.
- Machines, Tables and Bookcases lose the most money on discounts above 20%.
- Recommendation: cap discounts at 20% and review pricing on Furniture and Machines.

## Project structure
```
data/        superstore_raw.csv, superstore_clean.csv, superstore.db (created by the scripts)
scripts/     01_generate_data  02_clean_data  03_load_to_sqlite  04_run_queries  05_analysis_charts  06_build_excel
sql/         queries.sql (10 queries: aggregates, CASE, window functions LAG / RANK, CTE)
outputs/     Q1-Q10 CSVs, Sales_Analysis.xlsx, charts/*.png
powerbi/     POWERBI_GUIDE.md (step-by-step + DAX)
run_all.py   runs the whole pipeline
```

## How to run
```bash
# 1. Install Python 3.9+ from python.org, then in this folder:
pip install -r requirements.txt

# 2. Run everything
python run_all.py
```
Windows tip: open the folder, click the address bar, type `cmd`, press Enter, then run the commands above.

Run steps individually with `python scripts/02_clean_data.py` etc. To explore SQL yourself, open `data/superstore.db` in
**DB Browser for SQLite** (free) or MySQL Workbench (import `superstore_clean.csv`), and run `sql/queries.sql`.

## About the data
The dataset in this repo is **synthetic**, generated by `scripts/01_generate_data.py` to mirror the structure of the Kaggle
"Superstore Sales" dataset (same column names, with deliberate duplicates, missing values and messy text). It is not real company data.
To use the real file: download it from Kaggle, save as `data/superstore_raw.csv`, then run `python run_all.py`
(data generation is skipped automatically). Your numbers and insights will differ, so update the findings above.
